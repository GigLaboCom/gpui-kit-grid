Most WebGPU demos are 3D scenes. This one is an application's interface:
a data grid of 150 simulated quotes grouped by sector, where each cell
that changes flashes green or red and the sector rows keep live averages.
None of it is HTML. The table, its text and its scrollbars are drawn on
one canvas, at about 300 updates a second.

## How it is drawn

- **The interface is [GPUI](https://gpui.rs/)**, the UI framework of
  the Zed editor. It lays the window out and paints it on the GPU as
  quads, glyphs and paths.
- **The table is gpui-kit-grid**, a data grid for GPUI written in Rust.
  One element paints the visible cells; sorting and grouping run in the
  background, between frames in a browser.
- **The page runs WebAssembly.** The same Rust code that opens a desktop
  window is compiled for `wasm32-unknown-unknown`: about 7 MB to
  download, loaded when you press the button.
- **WebGPU first, WebGL 2 otherwise.** The demo asks the browser for a
  WebGPU adapter and falls back to WebGL 2 without one. The
  [same demo on WebGL 2](../demo/quotes/?backend=webgl) looks the same.
