## Try it

The quick start example, from a checkout of the repository: a window with 1000 trades that a producer thread keeps updating, sorted by price.

```sh frame="none" wrap
cargo run --release -p gpui-kit-grid --example quickstart
```

Its code is in [`crates/grid/examples/quickstart.rs`](https://github.com/GigLaboCom/gpui-kit-grid/blob/main/crates/grid/examples/quickstart.rs).
